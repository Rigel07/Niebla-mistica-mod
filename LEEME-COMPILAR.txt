SUBIRLO A GITHUB
 1. Descomprime este zip.
 2. En tu repositorio: Add file -> Upload files, y arrastra TODO el contenido de la carpeta descomprimida
    (src, .github, build.gradle, gradle.properties, settings.gradle, README.md, LICENSE, .gitignore...).
    Si ya tenias archivos sueltos de ChatGPT, borralos antes o se mezclaran.
 3. Commit changes.
 4. Pestana Actions: espera a que el Build salga en verde (3-5 min). Si no arranca, entra en "Build" -> Run workflow.
 5. Descarga el artefacto "niebla-mistica": dentro esta nieblamistica-1.2.0.jar.

SI NO SE VE LA CARPETA ".github" EN GITHUB (a veces no se sube al arrastrar):
 Add file -> Create new file, en el nombre escribe  .github/workflows/build.yml
 y pega el contenido del archivo build.yml de tu carpeta descomprimida (abrelo con el Bloc de notas). Commit.

EN MINECRAFT (Forge 1.20.1)
 - Pon el jar en la carpeta mods. Para probar: /mistica start   (necesitas ser OP / trampas activadas).

SI EL BUILD SALE EN ROJO: abre el Build fallido en Actions, copia las lineas que empiezan por "error:" y pasamelas.
